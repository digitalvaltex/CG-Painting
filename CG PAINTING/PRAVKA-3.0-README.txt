Правка 3.0 — знімок стану сайту
================================

Файл: index-pravka-3.0.html
  Копія index.html БЕЗ експериментального scroll-ефекту в блоці Werkwijze
  (збережено на момент перед додаванням process--scroll-exp).

Щоб відкотити лише цей блок: скопіюйте секцію <section id="werkwijze"> з index-pravka-3.0.html
у поточний index.html, або замініть увесь index.html на цю копію.

Дата створення знімка: див. час файлу index-pravka-3.0.html на диску.
